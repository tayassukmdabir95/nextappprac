PROJECT NAME: FitLog

FitLog is a responsive workout library and fitness planning application. Users can browse workouts, view exercise details, add lifts to today’s plan, save workouts for later, and track their workout totals.





## Technologies Used

- Next.js
- React
- Tailwind CSS
- Lucide React
- localStorage
- Netlify

## Key Features

1. Browse a responsive library of twelve workouts fetched from a local JSON data source.
2. Open individual workout detail pages with instructions, equipment, difficulty, sets, reps, duration, calories, and rating.
3. Add workouts to Today’s Plan with a maximum limit of five lifts.
4. Save workouts for later and switch between Today’s Plan and Saved tabs.
5. Track live exercise, duration, and calorie totals for the currently selected plan tab.
6. Search workouts by name or muscle group and sort workouts by duration, calories, or rating.
7. Mark planned workouts as done or remove workouts using the X button.
8. Persist planned and saved workouts with localStorage after page reloads.
9. Show toast notifications for workout actions and duplicate-plan attempts.
10. Support responsive layouts for mobile, tablet, and desktop screens.
